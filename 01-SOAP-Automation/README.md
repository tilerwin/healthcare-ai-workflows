# SOAP Automation

## Objective

Develop an AI-assisted workflow that transforms encounter transcriptions into clinician-reviewed SOAP note drafts.

---

## Current Workflow

Patient Encounter

↓

↓

SOAP Draft Generation

↓

Billing Code Suggestions

↓

Patient Exercise Recommendations

↓

Doctor Review

↓

Electronic Health Record
